# 后端API文档

1. 获取方法信息API

请求URL

GET /api/method/:id
请求参数

参数	类型	必填	描述
id	String	是	方法的唯一标识符
响应格式

{
    "status": "success",
    "data": {
        "methodId": "method-id",
        "englishName": "english-name",
        "chineseName": "chinese-name",
        "methodInputs": ["input1", "input2"],
        "methodOutputs": ["output1", "output2"],
        "briefIntroduction": "brief-introduction",
        "designPhase": "design-phase",
        "methodIntroduction": "method-introduction",
        "comparison": "comparison",
        "usageProcess": "usage-process",
        "promptTemplate": "prompt-template",
        "userInputExample": "user-input-example",
        "learningMaterials": "learning-materials",
        "difficultyLevel": "difficulty-level"
    }
}
```

## 2. 获取提示框内容API

### 请求URL
```
POST /api/prompt
```
### 请求参数
| 参数 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| url | String | 是 | API的URL |
| key | String | 是 | API的密钥 |
| history | Array | 是 | 历史会话数组 |

### 请求示例
```json
{
    "url": "https://api.example.com",
    "key": "your-api-key",
    "history": [
        {
            "role": "system",
            "content": "You are a helpful assistant."
        },
        {
            "role": "user",
            "content": "Who won the world series in 2020?"
        },
        {
            "role": "assistant",
            "content": "The Los Angeles Dodgers won the World Series in 2020."
        }
    ]
}
```

### 响应格式
```json
{
    "status": "success",
    "data": {
        "replyText": "reply text",
        "methodIds": ["method-id1", "method-id2"]
    }
}
```
注意：`methodIds`是一个包含方法ID的数组，这些方法ID对应于可以帮助处理当前提示的方法。

## 错误响应
如果请求失败，API将返回以下格式的响应：
```json
{
    "status": "error",
    "message": "Error message"
}
```
