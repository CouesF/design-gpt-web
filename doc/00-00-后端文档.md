以下是一个基于Node.js和Express的后端项目的示例文件结构。这个结构将API路由、控制器、模型和数据文件解耦，使得项目更容易维护和扩展。

```
/backend
│
├── /node_modules
│
├── /src
│   ├── /api
│   │   ├── /controllers
│   │   │   ├── methodController.js
│   │   │   └── promptController.js
│   │   │
│   │   ├── /models
│   │   │   └── methodModel.js
│   │   │
│   │   ├── /routes
│   │   │   ├── methodRoutes.js
│   │   │   └── promptRoutes.js
│   │   │
│   │   └── /utils
│   │       └── openaiUtils.js
│   │
│   ├── /data
│   │   └── method_data.js
│   │
│   └── server.js
│
├── package.json
└── package-lock.json
```

**文件说明：**

- `methodController.js`：包含处理获取方法信息API请求的控制器函数。
- `promptController.js`：包含处理获取提示框内容API请求的控制器函数。
- `methodModel.js`：定义方法的数据模型。
- `methodRoutes.js`：定义获取方法信息API的路由。
- `promptRoutes.js`：定义获取提示框内容API的路由。
- `openaiUtils.js`：包含调用OpenAI API的实用函数。
- `method_data.js`：包含方法详细信息的数据文件。
- `server.js`：启动Express服务器的主文件。
